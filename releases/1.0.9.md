# Clip2MD Obsidian 1.0.9

## 变更

- 高级设置新增“图片存放目录”，可手动填写 Vault 内路径，也可浏览选择文件夹。
- 留空时保留原有图片位置：笔记所在目录的 `_assets/task-任务ID`；选择 Vault 根目录时显示为 `/`。
- 自定义图片目录下的图片会使用相对于笔记的 Markdown 路径，支持笔记位于嵌套目录。
- 设置页按钮增加短时间重复点击保护，连接测试期间显示进行中状态。

## 兼容性

- Obsidian 1.13.7 及以上版本。
- 支持桌面端和移动端。

## 发布文件

- `main.js`
- `manifest.json`
- `styles.css`

三个发布文件均由 GitHub Actions 从本次版本 Tag 构建，并生成 GitHub artifact attestation，可使用 `gh attestation verify` 验证来源。
