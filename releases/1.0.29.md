# Clip2MD 1.0.29

- 新增智能笔记与原文展示顺序设置，默认智能笔记优先，可切换原文优先；预览、普通同步、日合并和本地受管理分区使用同一顺序，配置与备份保留选择。
- 同步本地剪藏扩展的知识星球、淘宝及正文提取能力配置与协议；桌面功能需另外安装 Clip2MD Desktop Tools 0.2.4。
- 云端失败任务本地恢复时，先校验并上传该任务的本地图片，再提交生成，避免云端笔记引用无法访问的 Vault 图片路径。
- 保留市场渠道的独立双插件分发，移除网站版自更新器和内置桌面运行时。

最低 Obsidian 版本为 1.13.1，主插件支持桌面和移动端。自动化测试与市场构建检查覆盖源码和打包；本次未执行真实账号、最低版本宿主、Windows 或 Intel Mac 实机验收。
