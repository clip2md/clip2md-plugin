# Clip2MD 1.0.26

- 同步独立市场渠道源码：主插件与本地剪藏扩展分别安装、启用和更新，通过 companion protocol 联动；市场版不包含网站版自更新器或内置桌面运行时。
- 增加桌面扩展控制、来源属性与模板变量、B站/抖音/小红书收藏导入、云端失败任务本地解析/转写恢复，以及本地诊断与用户反馈。
- 普通偏好按 Vault 保留，凭据与设备状态隔离；统一目录选择与素材目录配置。
- 修复市场版桌面入口遗留网站版变量导致的运行错误；新增产物冒烟检查，覆盖扩展缺失、不兼容和已连接三种状态。
- 明确说明云端服务的账号、付费权益与额度，以及本地恢复回传文本的条件、数据范围和隐私政策。
