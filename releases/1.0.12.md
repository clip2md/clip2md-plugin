# Clip2MD Obsidian 1.0.12

## 变更

- 新增高级设置“本地删除或改名后不再补回”，默认关闭，仅对当前 Vault 生效。开启后，原同步文件被删除、改名或移动的任务会被记住并单独统计，不再在原路径生成第二份；原文件仍在的任务及同一网址重新剪藏的新任务继续正常同步。
- 关闭该开关后，下次同步会尝试恢复被忽略的任务。网络或写入失败时可继续重试；原路径被其他文件占用时会避让，不覆盖已有文件。
- 发送“同步成功后删除”回执前会重新确认 Vault 文件仍存在且包含任务标记。原文件已被移走的待提交回执会丢弃；读取异常时保留待重试。

## 兼容性

- Obsidian 1.13.7 及以上版本，支持桌面端和移动端。
- 官方市场构建不包含插件自更新功能。

## 发布文件

- `main.js`
- `manifest.json`
- `styles.css`

三个发布文件由 GitHub Actions 从对应的版本 Tag 构建，并生成 GitHub artifact attestation。
