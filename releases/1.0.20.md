# Clip2MD Obsidian 1.0.20

## 中文

- 新增独立“博主订阅”设置子页，集中管理订阅概况、同步范围、归档目录、索引及日报；作品面板保留筛选和笔记操作。
- 支持博主搜索、单博主同步开关与指定目录、目录预览、显式保存和重置。后台刷新保留草稿、展开状态、输入焦点和光标位置。
- 保存期间禁用重复操作；账号或凭证变化时隐藏旧账号内容，并阻止过期请求覆盖新账号状态，包括 A→B→A 切换。
- 订阅接口及笔记属性采用逐项类型校验，兼容合法空值；未知云端状态保守展示。
- 保留用户批注、已有笔记路径、主动删除防重导入和删除回执保护；损坏订阅状态恢复前先备份并读回核验。
- 订阅面板及凭证校验异常独立处理，基础同步可继续启动。

最低支持 Obsidian 1.13.1。市场包由 Obsidian 管理更新，不包含自更新器。购买、续订、扫描配置和云端任务操作继续通过网页完成。

已完成 221 项自动化测试、类型检查、零警告 ESLint、生产构建、市场结构检查和 bundle 启动冒烟；独立干净构建的三个文件逐字节一致。原 Windows 故障设备、原生桌面/移动端及生产自动删除仍需单独验收。

## English

Adds a dedicated creator subscription settings page for synchronization scope, archive folders, indexes and daily reports. Drafts and input selection survive refresh. Credential changes invalidate stale operations, while annotations, existing paths and deletion receipt protections are preserved. The subscription panel remains separate from basic synchronization startup.

Requires Obsidian 1.13.1 or later. Community updates are managed by Obsidian. Automated verification passed 221 tests, type checking, lint, production build, structural validation, startup smoke and reproducible builds. Native device acceptance remains separate.
