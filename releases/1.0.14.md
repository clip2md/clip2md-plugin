# Clip2MD Obsidian 1.0.14

- Fix community-market source warnings by declaring ES2020 library types for the modern JavaScript APIs used by the plugin.
- Use Obsidian DOM creation helpers in note content settings and previews.
- Remove an unused import and an unnecessary type assertion.
- Replace CSS `!important` declarations with selectors scoped to Clip2MD settings.
- Expand the English README with features, requirements, and installation instructions.

Requires Obsidian 1.13.7 or later; supports desktop and mobile.
