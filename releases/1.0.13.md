# Clip2MD Obsidian 1.0.13

## 变更

- 扫码绑定改为两阶段完成：手机授权后等待插件把新 Key 保存到本机，插件确认后才创建新凭证并替换用户选定的旧 Key。合盖超过绑定码有效期时，未完成的请求不会撤销旧 Key。
- API Key 改存本机 SecretStorage；设备身份、同步游标、任务映射、忽略列表、待发回执和绑定会话改存本机状态。两台设备共享 Vault 配置时，各自的 Key 和同步进度不会互相覆盖。
- 首次升级从空游标重新检查任务，并按笔记内的任务标记重建映射。旧映射对应的笔记缺失且开启“不重导”时，先让用户选择保留忽略或重新导入。旧共享字段暂时保留，待所有设备升级后可从设置页清理。
- 本机 Key 返回 401 后暂停后台同步及回执重试，保留原 Key 和待发回执供检查；重新绑定后恢复。

## 兼容性

- Obsidian 1.13.7 及以上版本，支持桌面端和移动端。
- 需要服务端支持 Obsidian 绑定协议 v2；旧版插件仍由服务端 v1 接口兼容。
- 官方市场构建不包含插件自更新功能。
