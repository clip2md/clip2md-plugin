# Clip2MD Obsidian 1.0.13

## 变更

- API Key 改为保存在本机 SecretStorage，同步游标、文件映射、忽略列表和待发回执按本机保存，减少多设备共享 Vault 时的状态冲突。旧配置升级时保留迁移入口，请在每台设备分别绑定。
- 扫码绑定采用两阶段确认：本机保存凭据后再完成绑定；凭据失效时停止自动请求并保留待发回执，方便重新绑定。
- 优化同步设置页，新增笔记内容编辑与预览，支持标题选择、文件名变量和属性模板校验，减少模板错误导致的写入问题。
- 新安装使用改进的默认文件名与属性模板；已有自定义配置继续保留。
- 保留本地删除、改名和移动保护，以及写入成功后的同步回执校验。

## 兼容性

- Obsidian 1.13.7 及以上版本，支持桌面端和移动端。
- 官方市场构建不包含插件自更新功能。
- 扫码绑定依赖 Clip2MD 服务端对应协议；也可在设置页为本机配置 API Key。

## 发布文件

- `main.js`
- `manifest.json`
- `styles.css`

三个文件由 GitHub Actions 从版本 Tag 构建，并生成 GitHub artifact attestation。
