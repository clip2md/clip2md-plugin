# Clip2MD Obsidian 1.0.15

- Allow delete-after-sync after the selected content (full, note only, or source only) has been written and verified. Deleting partial content requires confirmation that the unsynchronized content will also be removed from the cloud.
- Verify image references against actual local attachments, including custom folders, Chinese names, spaces, and moved daily notes. Unselected or unused assets no longer inflate the required image count.
- When image sync is explicitly disabled, allow deletion after the nonempty text without images is saved and the user separately confirms permanent removal of unsaved images. Failed downloads in local image mode still retain the cloud task.
- Persist acknowledgements before sending; check the saved text and attachment hashes again before retrying. Changes to content, attachments, content mode, or image settings require resynchronization.

The new deletion rules require a Clip2MD server supporting v2 acknowledgements. Older servers retain the previous deletion rules. Requires Obsidian 1.13.7 or later; supports desktop and mobile. Community-market updates are managed by Obsidian.

## 中文

- 同步后删除支持完整内容、仅智能笔记、仅原文，核验所选正文实际写入后才提交回执。部分内容模式首次确认：“仅保存所选内容；删除后，未同步的内容也会从云端删除。”
- 图片改为核验最终引用与实际附件，支持自定义附件目录、中文及空格路径、移动目录后的合并日记；未选正文或未引用的素材不再造成图片数量误判。
- 主动关闭图片同步时，可核验去图后的非空正文并另行确认：“仅保存去图后的正文；未保存的图片也会随云端任务永久删除。”开启图片同步但下载失败仍保留云端任务，去图后正文为空也不删除。
- 回执持久保存后提交；重试前再次核对正文和附件哈希。内容、附件、同步内容模式或图片设置变化时撤回旧回执，等待重新同步。

新的删除规则需服务端支持 v2 回执；旧版服务端继续执行原有删除条件。任一已开启通道取得有效凭据后，整个云端任务及素材可能被永久删除，其他设备或通道可能尚未同步。最低 Obsidian 版本保持 1.13.7。
