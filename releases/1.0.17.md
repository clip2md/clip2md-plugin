# Clip2MD Obsidian 1.0.17

## Subscription archives

- Add a creator subscription panel with creator, platform, document type and sync status filters.
- Support configurable subscription folders, per-creator folder overrides, creator indexes and independent daily report folders.
- Link local works, comment supplements and daily reports. Keep existing note paths when folder templates or creator names change.
- Preserve annotations and user properties outside managed regions. Pause on edits or damaged boundaries; provide reviewed replacement, backups and conservative legacy-note migration.
- Persist creator sync exclusions and recover retained tasks when enabled again. Keep credentials and runtime progress on each device, with account-specific archive settings.
- Preserve unsaved directory drafts and input focus during background refresh.

## Availability and compatibility

Requires Obsidian 1.13.1 or later. The plugin declares desktop and mobile compatibility; this release has passed type checking, 186 tests, production build and market compliance checks. Native-device acceptance and production auto-delete acceptance remain separate checks.

The new subscription panel and subscription-aware archive protection require compatible Clip2MD server APIs. The compatible production APIs were deployed and verified before this release. When connecting to an older server, the panel displays an unsupported-server message and existing clipping sync remains available. The plugin does not purchase subscriptions, renew them, initiate paid clipping or provide unread, read-later or favorite states. Community-market updates are managed by Obsidian.
