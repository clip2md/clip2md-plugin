# Clip2MD Obsidian 1.0.19

## 中文

- 基于市场版 1.0.16 的源码重新发布，版本升级为 1.0.19。
- 保留 1.0.16 的剪藏同步、图片下载、设备绑定、内容偏好和同步后删除功能。
- 不包含 1.0.17–1.0.18 新增的博主订阅归档及相关启动逻辑。
- 最低 Obsidian 版本仍为 1.13.1，插件 ID 为 `clipmd`。
- 本次发布不代表 Obsidian 社区市场扫描已通过，审核结果以市场反馈为准。

## English

Republishes the community-market 1.0.16 source as version 1.0.19. The 1.0.16 clipping and synchronization features are retained. Blogger subscription features and their startup logic introduced in 1.0.17–1.0.18 are excluded.

Requires Obsidian 1.13.1 or later. Community scan approval is separate from this GitHub release.
