# Clip2MD Obsidian 1.0.11

## 变更

- 支持同步成功回执。用户在 Clip2MD 网页开启 Obsidian“同步成功后删除”后，插件仅在完整模式下成功写入 Markdown 和全部本地图片时提交回执；未满足条件时保留原任务并说明原因。待提交回执会在本地保存，临时网络失败或重启后继续重试。
- 新增 `{{source_title}}` 模板变量，可在 Markdown 正文、前置元数据、文件名和目标文件夹中使用原文标题。它独立于可编辑的任务标题；来源标题为空时输出空字符串，默认模板保持不变。

## 兼容性

- Obsidian 1.13.7 及以上版本。
- 支持桌面端和移动端。
- 官方市场构建不包含插件自更新功能。

## 发布文件

- `main.js`
- `manifest.json`
- `styles.css`

三个发布文件由 GitHub Actions 从对应的版本 Tag 构建，并生成 GitHub artifact attestation。
