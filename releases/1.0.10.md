# Clip2MD Obsidian 1.0.10

## 变更

- 按 Obsidian 官方建议，将按钮类型判断改为跨窗口安全的 `instanceOf(HTMLButtonElement)`。
- 保持连接测试按钮和设置页防重复点击逻辑不变。

## 兼容性

- Obsidian 1.13.7 及以上版本。
- 支持桌面端和移动端。

## 发布文件

- `main.js`
- `manifest.json`
- `styles.css`

三个发布文件均由 GitHub Actions 从本次版本 Tag 构建，并生成 GitHub artifact attestation，可使用 `gh attestation verify` 验证来源。
