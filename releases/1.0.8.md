# Clip2MD Obsidian 1.0.8

## 变更

- 修复“下载到本地”图片模式无法处理生产环境媒体 CDN 地址的问题。
- 对带短期签名的 CDN 图片使用稳定的本地文件名，避免重复生成图片文件。
- 无图模式移除 Markdown 图片和 HTML `<img>`，且不会下载图片。

## 兼容性

- Obsidian 1.13.7 及以上版本。
- 支持桌面端和移动端。

## 发布文件

- `main.js`
- `manifest.json`
- `styles.css`

三个发布文件均由 GitHub Actions 从本次版本 Tag 构建，并生成 GitHub artifact attestation，可使用 `gh attestation verify` 验证来源。
