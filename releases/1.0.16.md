# Clip2MD Obsidian 1.0.16

- Lower the minimum Obsidian version from 1.13.7 to 1.13.1, allowing Obsidian 1.13.4 to pass the installation version check.
- Add a prominent bilingual installation notice: if installation reports “No appropriate version found.”, check the Obsidian version and update it when below the supported minimum.
- Keep the existing settings status indicator, which uses an API introduced in Obsidian 1.13.1. No sync or deletion behavior changes.

Requires Obsidian 1.13.1 or later; supports desktop and mobile. HarmonyOS device operation still requires real-device verification. Community-market updates are managed by Obsidian.
